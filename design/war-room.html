Visual direction — proposal 01

The War Room

A reskin for Bush League. Same dense stat tables the genre runs on — pushed through the discipline of a trading floor instead of a spreadsheet.

Grounded in: Linear, Mercury and Coinbase's dashboard systems, Bloomberg Terminal's own accessibility rebuild, and the screen-zone grammar broadcast teams use to keep live esports stats readable — not a Dribbble mood board.

02 — The palette

One accent for action. One for what's happening right now.

Every premium dashboard we looked at enforces the same split: chrome and labels stay neutral, the brand accent touches data and controls only, and "direction" (up/down, good/bad) is its own channel entirely. 09 — What ships

If this is the one, here's the branch.

A reskin, not a rebuild — the page registry, the state, the actual game logic don't move. This is what actually changes in the codebase, in the order it'd ship.

01
Replace the palette + type stack in tokens.css
New --c-* values, --c-live added, Inter/JetBrains Mono swapped in behind the existing --shell-font-* tokens — every component that already reads a token needs zero changes.
02
Force tabular-nums globally
One line in the base stylesheet. Fixes column jitter everywhere at once.
03
Elevation + hairline pass
Rows move off flat 1px dividers onto the surface-tint system shown in 01 and 02.
04
Three new shared components
The tool-grade equalizer (ToolBars), the inline sparkline (Spark), and a radial gauge (Gauge, for reliability and anything else 0–100) — all used wherever a table column already has the data.
05
One .live treatment
The violet glow border, built once, applied to an in-progress game and a deadline countdown — nowhere else.
06
Roll it out: Draft → Office → Books
Newest page first since it's freshest in mind, then the two already-live pages, screenshotted at 360px in both themes before anything ships — same discipline as every pass so far.
07
Command bar + live wire — stretch, not part of the reskin
Real, unlike everything above: it needs actual search infrastructure and a real aggregated transactions feed, not just new CSS. Sections 04/05 show what the visual language could hold — worth a pass of its own, honestly scoped separately rather than folded into "just a reskin."
Reacting to this: which pieces land, which don't, and anything you'd push further before it becomes real code.
